# Cryp Tok Solutions — static clone

Production static build of the Cryp Tok Solutions site ("AI-Powered Everyday Apps"),
cloned from the original Replit project and rebuilt with Vite + React + Tailwind CSS v4.

- Live: https://cryptok.online
- Portfolio: 18 entries (#1 Prolice AI, #2 Bimyem Expressions, #3 REMU, 12 original
  portfolio apps, #16 Recoupa, #17 Fix Messy, #18 Atlas Games)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs dist/
```
